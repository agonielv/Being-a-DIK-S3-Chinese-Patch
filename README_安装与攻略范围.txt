S3 汉化＋Scrappy攻略整合 v1.4 TEST
适用：当前工程对应的 Steam 第三季 0.12.2.1。
原 Mod：Scrappy，BaDIK_0.12.1_scrappyMod.zip。

安装
1. 完全退出游戏。
2. 把本包 game 文件夹合并到游戏安装目录的 game，允许覆盖同名文件。
3. 启动游戏。进入剧情后，按 F7 或点击右上角“攻略 · F7”。F8 仍是修改器。
v1.3 用户直接合并升级。本包包含 v1.3 汉化、核心修改器和气泡字号修复。
只安装 game；维护源码、build_walkthrough.py 和报告不用放进游戏目录。
如果此前直接装过原 Scrappy 0.12.1 Mod 的剧情脚本，先恢复干净的 0.12.2.1 游戏，再安装本包。

攻略范围
本次“全章”是原 S3 Mod 的间章、第9—12章，不包含独立客户端的第1—8章。
原Mod的511处可对应标记已处理，合并两处重复后为509条提示：434个普通菜单选项（分布于321个菜单）、54个气泡选项、14条手机回复、5个重大抉择选项、2个拍照选项。
21段自由探索清单，218条有效收集记录：现金、收藏图和收集任务。房间内圈出未收集物；F7显示本段完整清单和完成状态。
第10—12章英语课实时剩余答案；派对猜人正确选项提示；机关盒第一面步骤；装饰箱位置和各章路线警示。
原Mod的其他机关盒面没有步骤，未虚构补充。
条件提示读取当前进度；相同选项按原剧情菜单分别绑定，存档回退后重新计算。
未标注选项不表示没有效果；原作者的攻略可能存在遗漏或判断误差。

界面
F7可开关选项提示和收集物圈选；F8中的气泡提示开关继续有效。
普通选项的提示独立小字显示，长菜单支持滚动。气泡保留v1.3的缩小字号。
手机、重大抉择和拍照提示仅修改显示内容，不改点击动作或聊天记录。
“原 Mod 标注选项”表示原作者只加了颜色，没有写具体后果；不额外推断其好坏。

与其他功能的边界
原Mod新增的8处多路线专用选项，原版剧情中不存在，已在覆盖报告逐条列明；没有插入这些新增剧情选择。
原Mod的两处出轨数值解释归入F7术语说明；路线中断警示集中于F7本章提醒。
小游戏跳关及多路线强制串行观看属于另外两类功能，本次没有加入。
v1.2遗留的整本笔记本图片等补图汉化事项不属于本次攻略迁移，仍未补齐。

验证与限制
通过：Python逻辑验证、原Mod标记对照、条件边界、重复菜单隔离、手机/拍照上下文隔离、缺失变量保护、中文字体字形、既有汉化逐字节一致、ZIP完整性。
未通过实际游戏测试：当前没有RenPy运行环境和完整游戏资源，不能保证启动、布局和全剧情流程已在游戏内验证。
如攻略未显示，打开F7查看是否提示匹配异常，并发来log.txt；如启动报错，发traceback.txt和log.txt。

致谢：原攻略规则来自 Scrappy。本包为独立适配，不代表原作者发布或认证。
