# Being a DIK Season 3 简体中文汉化补丁

## 项目简介

这是一个针对 **Being a DIK - Season 3** 制作的非官方简体中文汉化项目。

项目采用 **AI 初译 + 大模型上下文精校 + 实机检查与持续修正** 的方式完成文本本地化。

主要翻译流程：

1. 使用本地部署的 **Qwen3.5 8B** 对英文原文进行第一轮批量翻译；
2. 保留英文原始脚本作为上下文与语义参考；
3. 使用 **ChatGPT GPT-5.6 Sol** 对初译文本进行逐批精校、润色和一致性检查；
4. 根据角色关系、上下文、剧情前后文重新调整生硬或容易产生歧义的翻译；
5. 统一人物名称、称呼、专有名词和游戏术语；
6. 对菜单、教程、选项、自由探索提示、章节名称以及其他 UI 文本进行补充汉化；
7. 通过实机截图和游玩反馈继续检查漏翻、文本溢出、显示异常及上下文错误。

因此，本项目并不是简单地将机器翻译结果直接打包发布。

不过需要明确：

**本项目仍然属于 AI 辅助汉化项目，并非专业商业汉化。**

即使经过多轮检查，也无法保证所有文本都不存在误译、漏译、语境错误或表达不自然的问题。

如果发现问题，欢迎通过 GitHub Issues 提交。

# 翻译流程

## 1. 原始文本

首先从游戏脚本中提取英文原始文本。

英文原始脚本始终作为最终语义判断依据，避免因为初译文本本身存在错误而继续产生二次误译。

---

## 2. Qwen3.5 8B 初译

第一阶段使用本地运行的：

**Qwen3.5 8B**

进行大批量初译。

本地模型主要负责：

* 建立基础中文译文
* 完成大量重复结构文本
* 提供第一版对白
* 降低后续逐条处理的工作量

这一阶段更加侧重于覆盖率和基础语义，并不直接视为最终译文。

---

## 3. ChatGPT GPT-5.6 Sol 精校

完成初译后，再使用：

**ChatGPT GPT-5.6 Sol**

结合英文原文、剧情上下文以及已有译文进行第二阶段精校。

主要处理：

* 修正明显机翻
* 修正语义偏差
* 调整中文语序
* 根据说话角色调整语气
* 根据前后剧情恢复上下文
* 处理俚语、双关及口语表达
* 统一角色称呼
* 统一人物名称
* 统一游戏术语
* 减少逐字直译
* 修复变量、Ren'Py 标签等特殊结构
* 检查遗漏英文
* 对 UI 文本进行适配
* 尽量控制中文文本长度

部分重要剧情文本会多次重新检查。

---

## 4. 实机检查

单纯检查 `.rpy` 文件无法发现所有问题。

因此还会通过实际运行游戏检查：

* 英文残留
* UI 漏翻
* 教程漏翻
* 章节标题漏翻
* 选项漏翻
* 文本框溢出
* 气泡文字超出边界
* 特殊界面文本
* 动态生成文本
* 图片关联文本
* 游戏内书籍
* 自由探索界面
* Mod 功能与汉化之间的兼容问题

发现问题后会继续回到脚本中修正。

# 安装

> 不同 Release 的文件结构可能有所变化，请优先查看对应 Release 的说明。

一般情况下：

1. 安装对应版本的正版 Being a DIK Season 3；
2. 建议首先备份游戏目录及重要存档；
3. 下载本仓库 Releases 中对应游戏版本的汉化补丁；
4. 解压补丁；
5. 按压缩包内原有目录结构复制到 Being a DIK 游戏目录；
6. 如果补丁包含 `game` 文件夹，则将其与游戏原有 `game` 文件夹合并；
7. 启动游戏并检查中文是否正常加载。

建议不要同时安装多个来源不同的汉化补丁或修改器。

不同 Mod 同时修改相同 `.rpy`、`.rpyc`、Screen 或变量时可能发生冲突。

# 已知问题

由于 Being a DIK 的文本和界面结构较复杂，目前仍可能存在以下情况：

* 少量英文残留
* 某些特殊 UI 没有进入常规翻译模板
* 动态文本漏翻
* 图片中的英文无法直接通过普通文本替换
* 少数文本过长导致显示拥挤
* 气泡中文字数过多
* 个别角色语气不够自然
* 个别双关或俚语翻译存在不同理解
* 特殊路线缺乏足够实机测试
* Scrappy Mod 与汉化代码发生边缘兼容问题
* 游戏版本更新后旧补丁失效

这些内容会随着测试继续修正。
