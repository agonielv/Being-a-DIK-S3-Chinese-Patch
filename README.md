## 翻译与校对方法

### 分工方式

项目采用 **AI 辅助翻译与工程处理，人工制定规则、补充语境并提出审阅反馈** 的协作方式。

ChatGPT / Codex 参与英文重译、中文表达检查、批次整理及脚本验证；维护者负责确定风格、人名规则、场景信息和修订方向，并结合实际阅读及游玩反馈持续调整。

补丁内的译文已经预先生成并合入文件，玩家使用时无需配置 AI 翻译接口。

### 翻译原则

1. **以英文原文和场景为依据。**需要重译的句子重新理解英文，再组织中文；已有译文用于参考与对照。
2. **优先采用自然的中文表达。**根据说话对象、情绪和人物关系调整语序、主语省略及口语搭配。
3. **保留原作的信息和力度。**重要事实、否定关系、条件、时间、数量和人物态度都需要核对。
4. **保留人物差异。**正式谈话、日常闲聊、粗口、玩笑、独白和文学性叙述分别处理。
5. **控制标点密度。**按中文语义和实际停顿断句，减少不必要的逗号与碎句；有剧情作用的犹豫、打断和重复予以保留。
6. **结合剧情处理双关与伏笔。**对暂时含糊的说法保留悬念，对笑点核对上下句的呼应关系。
7. **统一姓名和称呼。**以 `S3_v2.6_人名修订明细.csv` 为项目内部人名依据，并结合身份、关系和实际语境处理称谓。
8. **保留可执行文本格式。**核对玩家姓名变量、文本标签、百分号转义及其他动态内容，确保文字能在游戏中正确呈现。

### 中文自然性检查

专项检查先把中文作为独立文本阅读，判断句子在中文语境中是否正常、通顺。发现问题后，再回到英文原文和上下文重新翻译。

每条重译完成后立即检查三遍：

| 检查轮次 | 关注内容 |
| --- | --- |
| 第一遍：中文表达 | 语序、搭配、主语与指代是否自然，人物说话是否顺口 |
| 第二遍：句式与节奏 | 标点是否必要，句子是否被切得过碎，上下句能否顺畅衔接 |
| 第三遍：语义与格式 | 原意、否定和条件关系、姓名、数量、变量及格式标签是否准确 |

章节完成后，对当轮未修改的译文再做两轮全量复查，继续查找遗漏的问题。后续收到明确场景反馈时，也会重新检查相关上下文。

### 工作簿记录

校对工作簿保留来源模块、原始行号、说话人、英文、当前中文及修订中文，便于定位和追踪。

- G 列记录准备采用的修订译文。
- 重译结果与当前译文完全相同时，G 列留空。
- G 列空白表示本次合并继续使用补丁中的当前译文。
- 相同英文出现在不同场景时，按各自位置和语境判断。

## 文本合并与工程处理

翻译内容按明确的脚本位置合并，重点保证译文和原有运行结构能够对应。

1. **准确定位。**结合来源文件、原始行号和说话人找到目标对白。
2. **采用明确修订。**仅把 G 列非空的内容写入对应位置；空白项沿用当前补丁文本。
3. **核对编译数据。**对相关 `.rpyc` 的两个数据槽分别处理并回读，确认修订落在正确对白上。
4. **核对动态格式。**检查 `[name]` 等插值、`{i}` / `{b}` 等标签、`%%` 及必要转义。
5. **分别检查交互。**对依赖任务文字或显示内容的判断，核对中英文记录、任务状态与点击条件。
6. **核对发行包。**检查压缩包完整性、预期文件差异及随包资源的一致性。

本轮 8,136 条修订已逐条回读核对。文本合并阶段对已定位的对白字段进行更新，交互兼容的代码调整另行核查和记录。

## 安装与升级

### 安装前

- 准备与当前补丁对应的第三季游戏，并确认启动的是第三季程序。
- 完全退出游戏，备份当前游戏文件和存档。
- 从本仓库的 Releases 获取对应完整包，并同时阅读发行包内的安装说明。
- 本说明以 Windows 桌面环境为主要安装场景。其他平台需要自行核对目录结构与运行条件。

### 纯净原版首次安装

1. 将完整补丁包解压到第三季游戏根目录，也就是游戏可执行文件所在的目录。
2. 合并压缩包中的 `game` 文件夹，并按提示覆盖对应文件。
3. 确认内容进入游戏已有的 `game` 目录，路径层级应当是 `游戏根目录/game/…`。
4. 直接启动第三季游戏。

**纯净原版首次安装完整包，覆盖完成后即可启动，无需先运行升级脚本。**

### 已安装旧补丁的游戏升级

1. 退出游戏并完成备份。
2. 将最新完整包合并覆盖到第三季游戏根目录。
3. 在游戏根目录运行 `upgrade_to_V3.2.cmd`。
4. 等待出现 `Version 3.2 is ready` 的完成提示，再启动游戏。
5. 保留脚本生成的 `backup_V3.2_…` 备份目录，方便需要时恢复。

升级入口会调用随包的 PowerShell 脚本，为旧版文件与编译缓存进行备份整理，使当前补丁文件按预期生效。备份目录保留在 `game` 之外即可。

### 主要文件

| 路径或文件 | 用途 |
| --- | --- |
| `game/` | 中文脚本、界面适配、字体、资源及辅助功能 |
| `upgrade_to_V3.2.cmd` | Windows 升级入口 |
| `upgrade_to_V3.2.ps1` | 升级处理与备份脚本 |

如需恢复安装前状态，请使用安装前备份及升级脚本生成的备份，并妥善保存后续新增的游戏进度。

## 攻略与辅助功能

### 选择提示与探索帮助

基于 Scrappy 的攻略／修改器基础，提供相应剧情选择提示、数值提示和部分自由探索帮助。提示是否出现取决于当前场景、路线和模组支持范围。

攻略提示可能提前透露选项收益、路线条件或探索目标，适合希望减少试错的玩家。

### 修改器

随包整合中文修改器界面，提供金钱、关系和部分变量的查看或调整，并显示出轨值等相关信息。请以游戏内当前可见的按钮和可用项目为准。

数值调整会影响后续剧情判断。需要比较路线或尝试不同设置时，建议先另存一个存档；关系数值、剧情标记和路线锁定之间仍可能有独立条件。

### 小游戏辅助

- **数学考试：**提供钻石位置提示开关，开启后在对应界面标出位置。
- **格斗：**提供“对手 1 生命值”按钮，可在对应战斗界面使用。
- **科学实验：**对颜色、速度等显示词条提供中文映射，内部实验变量沿用游戏所需值。

## 常见问题

### 安装完整包需要自己运行翻译程序吗？

正常游玩直接使用随包译文和适配文件即可，无需安装 Python、配置 AI 接口或重新处理工作簿。

### 什么时候需要运行 CMD？

纯净原版首次安装完整包，合并覆盖后直接启动。覆盖旧补丁升级时，按安装说明运行 `upgrade_to_V3.2.cmd`，等待完成提示。

### 能继续读旧存档吗？

当前补丁包含中英文任务、旧记录及回调的兼容处理，目的是支持既有存档继续使用。具体存档的可用性还取决于游戏版本、所在剧情状态和历史安装情况，升级前请保留备份。

### 攻略提示能保证进入指定路线吗？

提示用于帮助理解当前选择和部分条件。路线结果还可能受到前几章决定、长期数值、独立剧情标记及其他前置条件共同影响。

### 可以和其他补丁或模组一起用吗？

是否兼容取决于各自覆盖的脚本、界面和变量。使用额外模组前请备份，并记录安装顺序；反馈问题时注明叠加使用的内容。

### 更新后遇到异常怎么办？

先核对游戏版本、安装目录、补丁版本和升级步骤，再记录触发过程。可以附上报错文本、相关截图和必要的存档信息，通过 Issue 反馈。
